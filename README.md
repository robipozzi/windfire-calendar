# Windfire Calendar
This project manages Google calendar interactions using Pythong programs that wrap Google APIs.

## Activate Python Virtual Environment
The project makes use of Python Virtual Environment (have a look at https://www.hostinger.com/tutorials/how-to-create-a-python-virtual-environment for more information) to run python programs in an environment that is virtually segregated from the host.
